# KR Wardrobe Cleaner

Calibration-first Dalamud plugin for the Korean FFXIV client.

- Dalamud API 15
- .NET 10 / x64
- v0.1 only scans Dungeon Drip snapshots, lists Armoire-eligible dresser items, records KR-client restore UI events, and exports diagnostics.
- It does not batch-restore items yet.

Custom repository: `https://raw.githubusercontent.com/yaaung-ai/KRWardrobeCleaner/main/repo.json`
